数据小贴士

          

            

              
              
备份 / 换电脑
复制整个「埋点小岛数据」文件夹，放到 exe 旁边就行。移动程序时记得连这个文件夹一起移，只拷 exe 的话你的数据不会跟过去。

            

            

              
              
分享给同事
在上面「分享给同事」导出全部（勾上数据源样本和埋点字典），把文件发给对方；对方在「导入同事的规则」里导入，逐条确认要不要覆盖。

            

            

              
              
升级新版本
先点右上角「休息」退出，用新 exe 替换旧 exe，「埋点小岛数据」文件夹保留不动，你的数据一个都不会丢。
