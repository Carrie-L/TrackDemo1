# 埋点小岛 · 动森海岛风视觉设计规范

> 一句话感觉：**波光粼粼、阳光美好、海岛风情、心情灿烂、树林摇曳、饮料果汁、鲜花烂漫**。

## 1. 配色红线与核心色板

- **绝对禁止**：老蓝色 / 深蓝色 / 黑蓝色（如 `#2C6FA3`、`#1E3A5F`、`#5E7890` 等 `R < 95` 且蓝色偏深的暗冷蓝）；禁止暗沉中老年褐/灰黄。
- **主色板**：
  - 暖可可标题字：`text-wood-700`（`#664A30`）
  - 正文与辅助字：`text-ink`（`#58483C`）、`text-ink-soft`（`#86776B`）、`text-ink-faint`
  - 晴空浅蓝底/边：`#EBF7FE`、`#F4FAFF`、边框 `#CBE9FB` / `#D5ECFA`
  - 叶绿主强调（勾选/通过/主按钮）：`#63A950` + **纯白 SVG 勾**（勾选框禁黑勾）
  - 樱花柔粉（用例选中胶囊/轻退出按钮）：`#FCDCE6` 填色 + `#664A30` 字色（无边框、无勾选符号）
  - 奶油卡面：`#FFFFFF` / `#FFFDF8`（`bg-cream`）

## 2. 各页面关键视觉约定（勿回退）

### 首页 `#home`
- 欢迎横幅：第一行欢迎框顶部留白 `pt-[44px]`（较旧版下移 20px），下方按钮排间距 `gap-[34px]`（增加 20px）。
- 双主按钮放大为厚实果冻胶囊：**「开始实时调试」**（叶绿）+ **「测试用例」**（奶油白，注意按钮文案是「测试用例」而非「埋点字典」）。
- KPI 四卡带柔和海岛底色与右下角 `shell.png` 贝壳微水印。
- **「最近的问题」**列表卡片：纯白底（不要粉红底色块）。
- **「小芽助手 · 海岛贴士」**：框内去彩色底保持清爽留白，切换按钮文案简短为 **「换一个」**。
- **「规则文件」**卡片：保持原暖可可配色。

### 测试用例 `#cases` & 实时调试 `#live`
- 选中枚举值胶囊：`bg-[#FCDCE6] border-transparent text-wood-700`（**不要线框、不要对勾**）。
- 点位「上次失败」标记：细腻的浅粉小圆点胶囊，克制耐看。
- 点位序号使用 `.shell-badge` 贝壳数字徽章。
- **「展开其他字段」**与 **`+ 其他字段 key`** 虚线浅蓝胶囊：测试用例页与实时调试页必须**完全同款样式**。

### 校验报告 `#reports`
- 左侧报告列表栏宽 **`315px`**（`lg:grid-cols-[315px_1fr] gap-5`；曾缩到 248px，用户确认恢复 315px）。
- 字号：Tailwind 字号表整体比初版大 1px（xs 12.5 / sm 13.5 / base 14.5 / lg 16 / xl 18 / 2xl 21），行内 `text-[Npx]` 小字同步 +1px。
- 按日期分组，卡片正文**不放重复花哨小图标**（几十上百条也不眼花）。
- 卡片右下角使用极淡背景融合水印（`h-[30px] w-[30px] opacity-[0.24] group-hover:opacity-[0.34]`）：
  - 通过：`sprout.png`（嫩芽）
  - 失败：`fail.png`（凋落粉花）
  - 待确认/警告：`bud.png`（中等粗细紫粉花苞，不要太细也不要过胖）

### 侧边栏左下角「小芽卡片」与系统弹窗
- 在 `小芽陪你测埋点` 卡片下方，以浅蓝细线分隔放置两枚迷你胶囊：
  - **「运行日志」**：正常时晴空浅蓝 `#F4FAFF`，有后台未读异常时转淡粉红并显示 `异常日志 N`，同时小芽头像右下角状态灯由 `#63A950` 绿灯切换为脉冲粉红灯。
  - **「休息」**：淡樱花粉 `#FFF4F8`，点击先弹确认卡（若实时调试进行中给出温和提示），确认后切全屏晴空欢送页。

## 3. 3D 图标素材清单（`web/static/icons/`）
- `data.png`：热带海岛果汁饮料风（数据源）
- `template.png`：动森冒险地图风（模板）
- `bud.png`：中等线条花苞（待确认）
- `sprout.png` / `fail.png`：嫩芽 / 凋落粉花（通过 / 失败）
- `shell.png`：贝壳装饰（首页 / 弹窗标题 / 用例序号）
- 任何新增或替换的 3D 图标必须与现有图标保持一致的描边粗细、暖光影与留白比例。
