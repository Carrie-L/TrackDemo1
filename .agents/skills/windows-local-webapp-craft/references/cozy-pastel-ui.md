# 治愈系 / 动森海岛风高颜值 UI 设计准则

总结自多轮用户视觉反馈与 Pinterest 插画级交互打磨的核心准则，适用于明亮、清新、阳光治愈风格的本地效率工具。

---

## 1. 色彩红线（绝对遵守）

### 严格禁止
- **老蓝色 / 深蓝色 / 黑蓝色**：任何低亮度高蓝通道的冷暗蓝（如 `#1E3A5F`、`#2C6FA3`、`#5E7890` 等 `R < 95` 且 `B > R + 25` 的“老旧后台蓝”）。
- **中老年暗沉色调**：浑浊暗黄、脏土棕、高饱和刺眼红/荧光绿。
- **廉价卡片底色**：不要把本来应该清爽留白的列表卡片整块涂成粉红底或泥土底。

### 推荐色板（阳光海岛 · 波光粼粼）
- **主文字**：暖可可棕 `#664A30`（`wood-700`）、正文柔和深棕 `#58483C`（`ink`）、次要信息 `#86776B`（`ink-soft`）。
- **晴空底与描边**：`#EBF7FE`、`#F4FAFF`、边框 `#CBE9FB` / `#D5ECFA`（清透阳光天蓝，明度高、绝不发黑发沉）。
- **草地叶绿（正向 / 勾选 / 通过）**：`#63A950` 实心 + **纯白色对勾**（勾选框绝不用黑勾！）。
- **樱花柔粉（选中态 / 轻提示 / 柔和退出）**：`#FCDCE6` 填充 + `#664A30` 暖可可字（无生硬外框、不加多余对勾）；极浅悬停 `#FFF4F8`。
- **奶油白卡片**：`#FFFFFF` 或 `#FFFDF8`（`cream`），用极柔和的天空色微阴影营造空气感。

---

## 2. 控件质感与视觉减噪

### 2.1 高密度列表防眼花（数十上百条记录场景）
- **去掉重复花哨的前置小图标**：如果每行都有鲜艳的状态图标，列表长了会极度刺眼。
- **按日期分组**：用轻巧的日期分隔线 + `tabular-nums` 时间戳建立扫描节奏。
- **融入背景的极淡右下角水印**：状态用单个柔和 3D 图标放在卡片右下角，设 `opacity-[0.24]`（hover 微升至 `0.34`）、尺寸约 `28px–32px`，像贴在信纸角落的浅印花，既能一眼辨识状态又完全不抢正文视线。

### 2.2 选中态胶囊（如用例期望值选项）
- 选中态：**柔粉 `#FCDCE6` + 透明边框 + 无勾选符号 + 暖可可字色**，简洁高级。
- 未选中态：纯白底 + 浅天蓝细边框 `#D5ECFA` + 柔和灰棕字，hover 轻泛淡粉 `#FFF4F8`。
- 状态提示标签（如“上次失败”）：克制的淡粉圆点 + 小号柔和文字，不要大块高饱和警报红。

### 2.3 跨页面控件一致性
- 相同功能的交互件（例如测试用例与实时调试里的「展开其他字段」虚线胶囊 + 内联 `+ 其他字段 key` 输入框）在不同页面必须**完全统一外观与尺寸**，不出现“一边旧版一边新版”。
- 首页核心主按钮（如「开始实时调试」「测试用例」）要有清晰的视觉权重、充足的上下留白与果冻感圆角，不要和次级标签挤在一起。

### 2.4 3D 贴纸图标规范
- 同组图标必须保持**视觉重量与线条粗细一致**（避免两个苗条图标旁边配一个过胖或过细的图标造成违和）。
- 贴合海岛风主题意象：贝壳、果汁冷饮、冒险地图、嫩芽、花苞、凋落小粉花等；生成后统一去白底/边缘柔化并等比缩放至清晰尺寸。

## 3. 新增系统功能的 UI 融合原则

当工具需要新增“运行日志”“退出服务”等原本属于控制台/开发者的功能时：
- **绝不**在页面角落塞一个突兀的黑色终端按钮或刺眼红色“关机”图标。
- **融入已有容器**：例如嵌入侧边栏底部的吉祥物卡片下方，用细浅蓝分隔线隔开，左右两枚与整站同款圆角的小胶囊（晴空浅蓝「运行日志」+ 柔粉「休息」），状态灯贴在头像右下角（绿 = 正常 / 粉红脉冲 = 有异常）。
- **弹窗文案温柔拟人**：不用冷冰冰的“终止进程 PID 12345”，改用“让小岛休息一下吗？ / 安心退出服务 / 小岛已经安心休息啦”，但技术细节（`server.log` 路径、完整异常堆栈、复制按钮）一个不少。

---

## 4. 响应式与窄窗自检

- 多栏布局（如左列表 + 右详情）的列表栏宽度别为了窄屏一味压缩：埋点小岛实测 248px 太挤、用户要求恢复到 315px；窄窗时优先让右侧筛选条换行/折叠，而不是牺牲列表可读性。
- 用户觉得字小时，整体调 Tailwind `fontSize` 字号表（各级 +1px）并同步把行内 `text-[Npx]` 小字 +1px，比改 `html { font-size }` 更可控（不会连带撑大 rem 间距）。
- 改完任何样式后，在真实浏览器检查 `1440×900` 与缩窄窗口下的排版、折行与溢出。
